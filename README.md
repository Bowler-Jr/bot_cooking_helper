## 📌 О проекте

Telegram-бот «Кулинарный помощник» помогает пользователям:
- 🔍 искать рецепты по **названию**
- 🍅 находить блюда по **имеющимся продуктам**
- 📋 получать **случайный рецепт** (через просмотр всех)
- 🔄 **пересчитывать ингредиенты** на любое количество порций

Бот написан на языке **Python** с использованием библиотеки `python-telegram-bot`. База рецептов хранится в формате JSON.
